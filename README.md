# Habitat Home

A volunteer-build construction planner for a 1,200 sf custom home.

Track eight milestones from site work to handover — tasks, crew hours, a $120k materials cap, a week-by-week schedule, and uploaded drawings. Progress is saved in the browser.

## What's inside

- **Plan** — milestone checklist with notes, custom tasks, and a live house elevation
- **Schedule** — start date through handover across the crew calendar
- **Budget** — materials vs. the $120k cap, by trade
- **Drawings** — attach a floor plan or elevation to the set

Crew model: 5 retirees (weekday mornings) and 12 students (two 3-hour shifts).

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL printed in the terminal. `npm run build` produces a production build.

## Stack

React 19, TanStack Start / Router, Tailwind CSS v4, Zustand.

Built with Grok.
